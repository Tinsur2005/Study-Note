# SpringBoot 前后端交互实现增删改

本文实现在前文完成的登录与学生查询的基础上逐步完成增删改查的操作，并在前端显示，实现一个学生管理系统的Demo。

## 一、删除操作

### 1.1 前端

继 [第一节：SpringBoot入门](1-SpringBoot入门.md) 和 [第四节：Ajax](4-Ajax.md) 中使用的学生列表前端页面student_list.html，修改展该前端页面，在表格添加一列`操作`，并在每一行添加删除按钮。

> 需要注意的是，在删除操作时，一般在前端要使用`Axios.delete(url [, config ] )` 发送请求，其中 `config` 参数可省，相应的后端也要使用 `@DeleteMapping` 注解在 `controller` 类的方法上。
>
> **config参数写法**：
>
> ```json
> {
>     params: {},       // URL参数
>     headers: {},      // 请求头
>     timeout: 5000,    // 超时
> }
> ```

```java
<body>
    <a href="/student/toAdd" class="btn btn-primary btn-sm">添加学生</a>
    <table class="table table-striped table-bordered table-hover table-condensed">
        <tr>
            <td>ID</td>
            <td>名字</td>
            <td>年龄</td>
            <td>性别</td>
            <td>操作</td>
        </tr>
        <tr th:each="student:${list}">
            <td th:text="${student.id}">1</td>
            <td th:text="${student.name}">zhangsan</td>
            <td th:text="${student.age}">23</td>
            <td th:text="${student.gender}">男</td>
            <td>
                <a class="btn btn-primary btn-sm" th:href="@{|/student/toUpdate?id=${student.id}|}">编辑</a>
                <button type="button" class="btn btn-danger btn-sm"
                        th:onclick="|deleteById(${student.id})|">删除</button>
            </td>
        </tr>
    </table>
    <script src="https://cdn.jsdelivr.net/npm/axios/dist/axios.min.js"></script>
    <script>
        // axios.delete 的第二个参数是 config，用 { params: {...} } 作为 query 参数发送
        function deleteById(id) {
            let isDelete = confirm('确定要删除这条记录吗？');
            if (!isDelete) {
                return;
            }
            axios.delete('/student/deleteById', { params: { id: id } }).then(function (resp) {
                let result = resp.data;
                // Result.OK=1 成功，Result.ERROR=0 失败
                if (result.code == 1) {
                    alert(result.msg);
                    location.href = '/student/selectAll';
                } else {
                    alert(result.msg);
                }
            }).catch(function (error) {
                alert('请求失败，请稍后重试');
            });
        }
    </script>
</body>
```

### 1.2 后端

> 同上文中提到的前端使用 `delete` 请求，后端也要使用 `@DeleteMapping` 注解

在StudentController中新增方法：

```java
@DeleteMapping("/deleteById")
@ResponseBody
public Result deleteById(Integer id){
    int line = studentService.deleteById(id);
    if(line != 0){
        return Result.ok("删除成功");
    }else {
        return Result.error("删除失败");
    }
}
```

相应的，也要在**Service层**创建接口和实现类，在**DAO层**创建`Mapper`接口，以及在Mapper映射文件`StudentMapper.xml`中增加删除的SQL语句，这里不再赘述。

## 二、新增操作

### 2.1 前端

依旧是以前文提到的学生管理系统Demo为例，新增操作需要在 `templates` 模板文件夹下新增一个文件 `student_add.html` 用来存放新增学生表单。

提交表单时，绑定一个点击事件，实现点击按钮后使用 `axios.post` 请求向后端发送新增请求。

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>添加学生信息</title>
    <link rel="stylesheet" type="text/css" href="/static/bootstrap-3.4.1-dist/css/bootstrap.css"/>
</head>
<body>
    <div class="container">
        <h3>添加学生</h3>
        <form>
            <div class="form-group">
                <label for="name">姓名</label>
                <input type="text" class="form-control" id="name" name="name" placeholder="请输入姓名">
            </div>
            <div class="form-group">
                <label for="age">年龄</label>
                <input type="text" class="form-control" id="age" name="age" placeholder="请输入年龄">
            </div>
            <div class="form-group">
                <label for="gender">性别</label>
                <select class="form-control" id="gender" name="gender">
                    <option value="男">男</option>
                    <option value="女">女</option>
                </select>
            </div>
            <button type="button" class="btn btn-default" onclick="add()">添加</button>
        </form>
    </div>
    <script src="https://cdn.jsdelivr.net/npm/axios/dist/axios.min.js"></script>
    <script>

        function add() {
            let student = {
                name: document.getElementById("name").value,
                age: document.getElementById("age").value,
                gender: document.getElementById("gender").value,
            }
            if(student.name == "" || student.age == "" || student.gender == ""){
                alert("信息不能为空，请检查");
                return;
            }

            axios.post("/student/add",student).then(function (resp){
                let result = resp.data;
                if(result.code === 1){
                    alert(result.msg);
                    window.location.href = "/student/selectAll";
                }else{
                    alert(result.msg);
                }
            }).catch(function (error){
                console.log(error);
                alert("请求失败");
            });
        }
    </script>
</body>
</html>
```

### 2.2 后端

在此处仅演示 `StudentController` 类中和新增操作有关的代码，其中`toStudentAdd` 是转发到学生添加页面（也就是前文中提到的 `student_list.html` ）的方法。

相应的要在 `IStudentService` 接口创建对应方法并在`StudentService` 实现类中实现，在`StudentMapper` DAO层接口中创建对应方法，在 `StudentMapper.xml`  中填写对应SQL语句，**从这一块开始到下文将不再赘述这一流程。**

``` java
@RequestMapping("/toStudentAdd")
public String toStudentAdd(){
    return "student_add";
}

@PostMapping("/add")
@ResponseBody
public Result add(@RequestBody Student student){
    if(studentService.add(student) != 0 ){
        return Result.ok("添加成功");
    }else {
        return Result.error("添加失败");
    }
}
```

## 三、修改

### 3.1 前端

在 `templates` 模板文件夹下新增查询页面 `student_update.html`，并在student_list.html页面新增一个修改按钮

查询按钮在原有表单的删除按钮前面新增一个按钮，并实现点击事件 `update`：

```html
<td>
    <button class="btn btn-info btn-sm"
            th:onclick="|update(${student.id})|">
        修改
    </button>
    <button class="btn btn-danger btn-sm"
            th:onclick="|deleteById(${student.id})|">
        删除
    </button>
</td>
```

使用JavaScript实现点击事件，完成页面转发，并使用 `get` 请求将id传回后端：

```javascript
function update(id){
location.href = "/student/toStudentUpdate?id="+id;
}
```

### 3.2 后端

```java
@RequestMapping("/toStudentUpdate")
public String toStudentUpdate(Integer id, Model model){
    Student student = studentService.selectById(id);
    model.addAttribute("student",student);
    return "student_update";
}

@RequestMapping("/updateById")
@ResponseBody
public Result updateById(@RequestBody Student student){
    if(studentService.updateById(student) != 0 ){
        return Result.ok("修改成功");
    }else {
        return Result.error("修改失败");
    }
}
```
