# SpringBoot - 拦截器 HandlerInterceptor

## 一、概述

### 1.1 定义

拦截器（`HandlerInterceptor`）是**SpringMVC 核心组件**，基于 Java 反射与 Spring 机制实现，专门用于拦截 Controller 层请求，在请求处理前、中、后进行统一增强处理，实现业务逻辑解耦。

### 1.2 核心作用

统一抽取 Web 项目通用重复逻辑，专注业务代码开发，常见使用场景：

- 身份校验：Token、Session、登录状态拦截校验
- 权限控制：接口访问权限、角色权限拦截
- 日志处理：统一记录请求地址、参数、响应耗时、操作者信息
- 请求预处理：统一编码、请求参数封装、请求头校验
- 风控处理：接口防重提交、简易限流、非法请求拦截

### 1.3 特性

- 归属体系：属于 **SpringMVC** 组件，不属于原生 Servlet
- 拦截范围：仅拦截 **Controller 接口请求**，默认不拦截静态资源
- 容器依赖：隶属于 Spring IOC 容器，可直接注入 Service、Mapper 等 Bean
- 设计思想：基于 AOP 面向切面思想，无侵入增强请求逻辑

## 二、拦截器核心方法

SpringBoot 推荐实现 `HandlerInterceptor` 接口（默认方法，按需重写），包含三个核心生命周期方法。

### 2.1 preHandle 请求预处理

```java
default boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler)
```

- **执行时机**：Controller 目标方法**执行之前**
- **核心用途**：登录校验、权限拦截、请求合法性校验
- **返回值说明**： true：放行请求，继续执行后续流程
- false：拦截请求，直接终止本次请求，不会执行 Controller、postHandle、afterCompletion

### 2.2 postHandle 请求后处理

```java
default void postHandle(HttpServletRequest request, HttpServletResponse response, Object handler, ModelAndView modelAndView)
```

- **执行时机**：Controller 方法执行完毕，**视图渲染之前**
- **核心用途**：修改视图数据、统一封装返回结果、二次加工响应数据
- **注意事项**：如果接口抛出异常、preHandle 返回 false，该方法**不会执行**；前后端分离项目基本用不到

### 2.3 afterCompletion 最终收尾处理

```java
default void afterCompletion(HttpServletRequest request, HttpServletResponse response, Object handler, Exception ex)
```

- **执行时机**：整个请求流程完全结束（视图渲染完成 / 请求异常终止）
- **核心用途**：资源释放、请求耗时统计、最终日志记录、异常信息归集
- **核心特性**：只要 preHandle 返回 true 放行，该方法**一定会执行**，不受接口异常影响

## 三、登录拦截器

### 3.1 自定义拦截器

新建一个包`interceptor`，在包中新建一个类 `interceptor`，实现 `HandlerInterceptor` 接口，并重写 `preHandler` 方法：

```java
public class LoginInterceptor implements HandlerInterceptor {
    @Override
    public boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler) throws IOException {
        HttpSession session = request.getSession();
        User user = (User) session.getAttribute("user");
        if(user == null){
            response.sendRedirect("/user/toLogin");
            return false;
        }
        return true;
    }
}
```

### 3.2 注册拦截器

通过配置类实现 `WebMvcConfigurer`，将自定义拦截器注册到 Spring 容器，配置拦截/放行路径。

新建一个包 `config` ，在包中新建类 `WebConfig` ，实现 `WebMvcConfigurer` 接口，并重写 `addInterceptors` 方法：

```java
@Configuration
public class WebConfig implements WebMvcConfigurer {
    @Override
    public void addInterceptors(InterceptorRegistry registry) {
        //拦截所有请求
        registry.addInterceptor(new LoginInterceptor())
                .addPathPatterns("/**")
                .excludePathPatterns("/user/toLogin","/user/login", "/static/**");
    }
}
```

> 其中 `addPathPatterns("/**")` 即拦截所有请求，`excludePathPatterns` 用来排除不经过拦截器的URL，需注意要排除`static`中的静态资源
