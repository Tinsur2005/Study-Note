# SpringBoot 常用注解

## 一、启动与核心注解

### 1.1 @SpringBootApplication

**作用**：SpringBoot项目启动入口核心注解，是一个组合注解，整合了 `@Configuration`、`@EnableAutoConfiguration`、`@ComponentScan` 三大功能。

**核心能力**：标识当前类为配置类、开启自动配置、自动扫描当前包及子包下的所有组件（Controller、Service、Component等）。

**使用场景**：仅用于项目启动主类。

```java
import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

// 项目启动核心注解
@SpringBootApplication
public class DemoApplication {
    public static void main(String[] args) {
        // 启动SpringBoot项目
        SpringApplication.run(DemoApplication.class, args);
    }
}
```

## 二、Web开发常用注解（Controller层）

### 2.1 @RestController

**作用**：组合注解，整合 `@Controller` + `@ResponseBody`。

**核心能力**：标识当前类为接口控制器，所有方法返回值自动转为JSON格式响应前端，无需单独加`@ResponseBody`。

**使用场景**：前后端分离项目的接口控制器类。

### 2.2 @RequestMapping/@GetMapping/@PostMapping

**作用**：绑定请求URL与接口方法，映射客户端请求。

- `@RequestMapping`：通用请求映射，支持GET/POST等所有请求方式
- `@GetMapping`：仅匹配GET请求（查询操作）
- `@PostMapping`：仅匹配POST请求（新增/提交操作）

```java
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
@RequestMapping("/user") // 类级别统一请求前缀
public class UserController {

    // GET请求：查询用户信息
    @GetMapping("/get")
    public String getUserInfo() {
        return "查询用户信息成功";
    }

    // POST请求：新增用户
    @PostMapping("/add")
    public String addUser() {
        return "新增用户成功";
    }
}
```

>  `RequestMapping` 也可以指定GET/%%POST%%：
>
>  ```java
>  @RequestMapping(value = "example" , method = {RequestMethod.POST})
>  @RequestMapping(value = "example" , method = {RequestMethod.GET})
>  ```

### 2.3 @RequestParam

**作用**：接收前端**普通参数（URL拼接参数、表单参数）**，可指定参数名、设置是否必传、默认值。

```java
// 接收URL参数：/user/getById?id=1001
@GetMapping("/getById")
public String getUserById(@RequestParam(value = "id", required = true, defaultValue = "1") Integer userId) {
    return "查询ID为" + userId + "的用户";
}
```

### 2.4 @RequestBody

**作用**：接收前端**JSON格式请求体参数**，常用于POST/PUT请求，自动将JSON转为Java对象。

```java
// 接收JSON参数：{"username":"张三","age":20}
@PostMapping("/save")
public String saveUser(@RequestBody User user) {
    return "保存用户：" + user.getUsername() + "，年龄：" + user.getAge();
}

// 实体类
class User {
    private String username;
    private Integer age;
    // getter/setter
    public String getUsername() { return username; }
    public Integer getAge() { return age; }
}
```

### 2.5 @PathVariable

**作用**：接收**URL路径变量参数**，RESTful风格接口专用。

```java
// 接收路径参数：/user/1001
@GetMapping("/{id}")
public String getUserDetail(@PathVariable("id") Integer id) {
    return "路径参数查询用户ID：" + id;
}
```

## 三、Bean 注册注解（组件注入）

作用：将自定义类交给Spring IoC容器管理，自动创建Bean对象，实现依赖注入。

### 3.1 四大基础组件注解

- `@Controller`：标注控制层组件（Web接口）
- `@Service`：标注业务逻辑层组件
- `@Repository`：标注数据访问层（DAO/Mapper）组件
- `@Component`：通用组件注解（不属于以上三层的工具类、公共类）

### 3.2 @Service 示例

```java
import org.springframework.stereotype.Service;

// 将业务类交给Spring管理
@Service
public class UserService {
    public String getUserServiceInfo() {
        return "业务逻辑执行成功";
    }
}
```

### 3.3 @Autowired

**作用**：自动装配Bean，根据**类型**自动注入容器中的组件，无需手动new对象。

```java
@RestController
@RequestMapping("/user")
public class UserController {

    // 自动注入UserService
    @Autowired
    private UserService userService;

    @GetMapping("/service/test")
    public String testService() {
        return userService.getUserServiceInfo();
    }
}
```

### 3.4 @Configuration+@Bean

**@Cnfiguration**：标识当前类为配置类，用于自定义Bean配置

**@Bean**：将方法返回值注册为Spring Bean，交由容器管理

```java
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

@Configuration
public class CustomConfig {

    // 自定义Bean，可在全局任意位置注入
    @Bean
    public String customBean() {
        return "自定义配置Bean";
    }
}
```

## 四、配置属性注解

### 4.1 @Value

**作用**：读取 `application.properties/application.yml` 配置文件中的属性值，注入到变量中。

**配置文件（application.yml）**：

```yaml
server:
  port: 8080
user:
  name: 李四
  age: 25
```

**代码示例**：

```java
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Component;

@Component
public class ConfigValueDemo {

    // 读取配置文件属性
    @Value("${user.name}")
    private String userName;

    @Value("${user.age}")
    private Integer userAge;

    public void printConfig() {
        System.out.println("用户名：" + userName + "，年龄：" + userAge);
    }
}
```

### 4.2 @ConfigurationProperties

**作用**：批量绑定配置文件前缀属性，适合配置较多的场景，比@Value更简洁。

```java
import org.springframework.boot.context.properties.ConfigurationProperties;
import org.springframework.stereotype.Component;

// 绑定前缀为user的所有配置
@Component
@ConfigurationProperties(prefix = "user")
public class UserConfig {
    private String name;
    private Integer age;
    // getter/setter
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
    public Integer getAge() { return age; }
    public void setAge(Integer age) { this.age = age; }
}
```

## 五、事务注解

### @Transactional

**作用**：开启事务管理，保证数据库操作原子性（要么全部成功，要么全部回滚）。

**使用场景**：Service层增删改复杂业务、多数据库操作场景。

```java
import org.springframework.transaction.annotation.Transactional;
import org.springframework.stereotype.Service;

@Service
public class OrderService {

    // 开启事务，方法执行异常自动回滚
    @Transactional(rollbackFor = Exception.class)
    public void createOrder() {
        // 1. 创建订单
        // 2. 扣减库存
        // 3. 异常测试：出现异常自动回滚所有操作
        int i = 1 / 0;
    }
}
```

**关键属性**：`rollbackFor = Exception.class` 表示捕获所有异常触发回滚（默认仅回滚运行时异常）。

## 六、切面与日志注解

### 6.1 @Aspect

**作用**：标识当前类为切面类，用于AOP切面编程，实现日志记录、权限校验、性能监控等通用功能。

### 6.2 @Slf4j

**作用**：Lombok日志注解，快速生成日志对象，简化日志输出代码。

**前置依赖**：项目引入lombok依赖。

```java
import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Component;

@Slf4j
@Component
public class LogDemo {
    public void printLog() {
        log.info("普通信息日志");
        log.error("错误日志");
        log.debug("调试日志");
    }
}
```

## 七、异常处理注解

### 7.1 @RestControllerAdvice

**作用**：全局异常处理注解，统一捕获所有Controller的异常，返回标准化JSON响应。

### 7.2 @ExceptionHandler

**作用**：指定捕获的异常类型，自定义异常返回结果。

```java
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;

@RestControllerAdvice
public class GlobalExceptionHandler {

    // 捕获所有运行时异常
    @ExceptionHandler(RuntimeException.class)
    public String handleRuntimeException(RuntimeException e) {
        return "系统异常：" + e.getMessage();
    }

    // 捕获所有异常
    @ExceptionHandler(Exception.class)
    public String handleException(Exception e) {
        return "全局异常：" + e.getMessage();
    }
}
```

## 八、总结

| 注解                            | 核心作用                     | 使用层级       |
| :------------------------------ | :--------------------------- | :------------- |
| @SpringBootApplication          | 项目启动、自动配置、组件扫描 | 启动类         |
| @RestController                 | 标识接口控制器，返回JSON     | Controller类   |
| @Service/@Component             | 注册业务Bean，交给Spring管理 | 业务类/工具类  |
| @Autowired                      | 自动注入Bean对象             | 属性/方法      |
| @Value/@ConfigurationProperties | 读取配置文件属性             | 配置类/组件类  |
| @Transactional                  | 开启数据库事务               | Service方法/类 |
| @RestControllerAdvice           | 全局统一异常处理             | 全局异常类     |
