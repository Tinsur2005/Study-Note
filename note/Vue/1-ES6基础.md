# Vue前置基础：ES6基本语法

## 一、JS 面向对象基础

JavaScript 最初没有类的概念，可直接创建对象，对象支持预设成员，也可动态新增成员。常用两种创建对象方式：字面量（JSON）方式、构造函数方式。

```javascript
// 1、字面量方式创建对象
var obj = {};
console.log(obj);

var student = {
    name : 'zhangsan',
    age : 23,
    study : function() {
        console.log(this.name + '在学习');
    }
}
// 动态给对象添加成员属性和方法
student.gender = '男';
student.show = function() {
    console.log(this.name + ': show');
}
student.show();
console.log(student);

// 2、构造函数的方式创建对象
function Animal() {
    this.name = 'kitty';
    this.age = 23;
    this.run = function() {
        console.log(this.name + ' 正在跑步');
    }
}
var cat = new Animal();
cat.run();
```

## 二、ES6 简介

ECMAScript 6.0（简称 ES6）是 JavaScript 语言的下一代标准，于 **2015 年 6 月正式发布**。其核心目标是让 JavaScript 支持复杂大型应用开发，成为企业级后端、前端通用开发语言。

### ECMAScript 与 JavaScript 的关系

1996 年 11 月，Netscape 将 JavaScript 提交至 ECMA 标准化组织。1997 年，ECMA 发布 **ECMA-262** 标准，将浏览器脚本语言统一命名为 ECMAScript。

**核心关系**：ECMAScript 是 JavaScript 的语法规范标准，JavaScript 是 ECMAScript 的主流实现，其他实现方言包含 Jscript、ActionScript。

ES6 是前端开发、Vue/React 框架学习的必备基础，完整进阶学习可参考阮一峰开源教程：https://es6.ruanyifeng.com/#docs

## 三、let 声明变量

ES6 新增 `let` 命令声明变量，用于替代部分 `var` 场景，核心特性：**块级作用域**，仅在当前代码块内有效，无变量提升。

```javascript
// let 块级作用域特性
{
    let a = 10;
    var b = 1;
}
// console.log(a); // ReferenceError: a is not defined 块外无法访问
console.log(b); // 1 var 无块级作用域

// for 循环计数器最适合使用 let，每次循环独立作用域
for (let i = 0; i < 10; i++) {
    // 循环体逻辑
}
// console.log(i); // ReferenceError: i is not defined
```

## 四、const 声明常量

`const` 用于声明**只读常量**，规则严格，核心特性：块级作用域、不可修改、必须初始化。

```javascript
// 1. 常量声明后不可修改
const PI = 3.1415;
// PI = 3; // TypeError: Assignment to constant variable. 报错

// 2. 声明必须立即初始化，不能空置
// const foo; // 'const' declarations must be initialized. 报错

// 3. 同 let 一致，仅块级作用域有效
{
    const MAX = 5;
}
// console.log(MAX); // Uncaught ReferenceError: MAX is not defined 块外无法访问
```

## 五、解构赋值（重点）

解构赋值是 ES6 对赋值运算符的扩展，通过**模式匹配**，快速从数组、对象中提取值并赋值给变量，简化取值代码。

```javascript
// 1、数组解构赋值
// 传统赋值
let a = 1;
let b = 2;
let c = 3;
console.log(a, b, c);

// ES6 数组解构
let [x, y, z] = [1, 2, 3];
console.log(x, y, z); // 1 2 3

// 2、对象解构赋值
let student = {
    name: "zhangsan",
    age: 23
};

// 传统取值
let name1 = student.name;
let age1 = student.age;

// ES6 对象解构
let { name, age } = student;
console.log(name); // "zhangsan"
console.log(age); // 23
```

## 六、模板字符串

模板字符串是加强版字符串，使用**反引号 \`\`** 包裹，支持多行字符串、变量嵌入、表达式运算、函数调用，彻底解决传统字符串拼接繁琐问题。

```javascript
// 1、字符串插入变量和表达式。变量名写在 ${} 中，${} 中可以放入 JavaScript 表达式。
// 	  需要注意使用反引号包裹
let name = 'Mike'
let age = 27
let info = `My Name is ${name},I am ${age+1} years old next year.`
console.log(info) // My Name is Mike,I am 28 years old next year.

// 2. 嵌入函数调用
function f(){
    return 'have fun!'
}
let str2 = `Game start,${f()}`
console.log(str2);  // Game start,have fun!
```

## 七、函数优化

ES6 对函数进行大幅优化，新增**参数默认值**、**不定参数**特性，简化函数参数处理逻辑。

```javascript
// 1、函数参数默认值
// 在ES变以前，我们无法给一个函数参数设置默认值。只能采用变通写法实现默认值
function add(a , b) {
    if(!b) {
       b = 1
    }
    return a + b;
}
console.log(add(10)); // 11

// ES6 原生参数默认值
function add2(a , b = 1) {
    return a + b;
}
console.log(add2(10)); // 11

// 2、不定参数 ...变量名
// 用于接收不确定个数参数，只能放在参数列表最后，且仅有一个
function fun(...values) {
  console.log(values.length)
}
fun(1, 2) // 2
fun(1, 2, 3, 4) // 4
```

## 八、箭头函数（重点）

箭头函数是 ES6 函数简写方式，语法：`参数 => 函数体`，简洁高效，常用于回调函数、数组方法。**注意：箭头函数无独立 this，无法作为构造函数**。

```javascript
// 1、单个参数箭头函数
// 传统函数
let print1 = function (obj) {
    console.log(arg);
}
print1('abc')

// 箭头函数简写
let print2 =  arg => console.log(arg)
print2('abcd')

// 多行函数体需包裹 {}
let print3=  (arg) => {
    console.log(arg)
}
print3('abcdef')

// 2、多个参数 / 无参数
// 多参数必须加 ()
let sum1 = function (a , b) {
    return a + b;
}
let sum2 = (a, b) => {
    return a + b;
}
// 单行返回可省略 {} 和 return
let sum3 = (a,b) => a + b;

// 3、对象方法简写对比
let person = {
    name: "jack",
    // 以前：
    eat1: function (food) {
        console.log(this.name + "在吃" + food);
    },
    // 箭头函数：无自身this，需直接访问对象
    eat2: food => console.log(person.name + "在吃" + food),
    // ES6 方法简写（推荐）
    eat3(food){
        console.log(this.name + "在吃" + food);
    }
}
person.eat1('米饭')
person.eat3('面条')
```

## 九、数组 map 与 reduce 方法

ES6 为数组新增高阶方法`map`、`reduce`，替代传统 for 循环，简化数组遍历、运算、映射逻辑。

### 9.1 map 方法

遍历原数组，通过回调函数处理每一个元素，返回**全新数组**，不修改原数组，常用于数组格式转换。

```javascript
let arr = ['1','20','-5','3'];
console.log(arr);

// 传统循环转换
let array = new Array();
for (let i = 0; i < arr.length; i++) {
    array.push(parseInt(arr[i]));
}
console.log(array);

// ES6 map + 箭头函数简化
let newArr = arr.map(item =&gt; parseInt(item))
console.log(newArr);
```

### 9.2 reduce 方法

累计处理数组所有元素，最终返回**单个结果值**。参数：回调函数（必选）、初始值（可选）。回调接收两个核心参数：上一次运算结果、当前遍历元素。

```javascript
let arr1 = [1,20,-5,3];

// 基础累加
let result1 = arr1.reduce(function (a, b) {
    console.log(a, b)
    return a + b
})
console.log(result1); // 19

// 箭头函数简化累加
let result2 = arr1.reduce((a, b) => a + b)
console.log(result2); // 19

// 累乘运算
let result3 = arr1.reduce((a, b) => a * b)
console.log(result3); // -300

// 设置初始值为0
let result4 = arr1.reduce(function (a, b) {
    console.log(a, b)
    return a + b
}, 0)
console.log(result4); // 19

let result5 = arr1.reduce((a, b) => a + b, 0)
console.log(result5); // 19
```

## 十、对象简写语法（核心重点）

ES6 支持对象属性、方法简写，当**变量名与对象属性名一致**时，可直接省略赋值语句，简化代码。

```javascript
let age = 12
let name = "Amy"

// ES5 传统写法
let person1 = {
    name: name, 
    age: age
}
console.log(person1);

// ES6 属性简写（键名与变量名一致，直接写变量名）
let person2 = {name, age}
console.log(person2); // {name: "Amy", age: 12}
```

## 十一、对象拓展运算符

拓展运算符 `...` 可取出对象所有可遍历属性，支持**对象浅拷贝**、**多对象合并**，是对象复制、合并的常用简洁写法。

```javascript
// 1、对象浅拷贝
let person1 = {name: "Amy", age: 15}
let someone = {...person1};
console.log(someone); // {name: 'Amy', age: 15}

// 2、多对象合并
let person2 = {gender: '男', address: '北京'};
let person = {...person1, ...person2};
console.log(person); // {name: 'Amy', age: 15, gender: '男', address: '北京'}
```

## 十二、Object 新增常用方法（重点）

ES6 为 Object 挂载多个静态方法，快速获取对象键、值、键值对，以及实现对象合并拷贝，日常开发高频使用。

- **Object.keys(obj)**：获取对象所有键名，返回数组
- **Object.values(obj)**：获取对象所有键值，返回数组
- **Object.entries(obj)**：获取对象所有键值对，返回二维数组
- **Object.assign(target, ...source)**：合并多个源对象到目标对象，实现浅拷贝、对象合并

```javascript
let person = {
    name: 'jack',
    age: 21,
    language: ['java', 'js', 'css']
}

// 获取键名数组
console.log(Object.keys(person)); // ["name", "age", "language"]
// 获取键值数组
console.log(Object.values(person)); // ["jack", 21, Array(3)]
// 获取键值对二维数组
console.log(Object.entries(person)); // [Array(2), Array(2), Array(2)]

// Object.assign 对象合并
let target = { name: 'zhangsan' };
let source1 = { age: 24 };
let source2 = { gender: '男' };
Object.assign(target, source1, source2);
console.log(target); // {name: 'zhangsan', age: 24, gender: '男'}
```
