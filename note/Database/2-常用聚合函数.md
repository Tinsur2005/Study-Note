# MySQL常用聚合函数

## **一、字符串函数**

用于处理文本、字符串拼接、截取、替换、去空格等操作

### 1. CONCAT() 字符串拼接

**语法**：CONCAT(str1,str2,...strN)

**参数**：str1~strN：多个字符串/字段，支持任意数量参数

**功能**：拼接多个字符串，**任意一个参数为 NULL，结果直接返回 NULL**

**示例**：`SELECT CONCAT('姓名：',name,'年龄：',age) FROM user;`

### 2. CONCAT_WS() 分隔符拼接

**语法**：CONCAT_WS(separator,str1,str2,...)

**参数**：separator：固定分隔符（必填）；后续为待拼接字符串

**功能**：带分隔符拼接，**自动忽略 NULL 值**，不会返回空结果

**示例**：`SELECT CONCAT_WS(',','张三',18,'北京');` -- 结果：张三,18,北京

### 3. SUBSTRING() / SUBSTR() 字符串截取

**语法**：SUBSTRING(str,start,length)

**参数**：str：目标字符串；start：起始位置（**从1开始**，负数从末尾倒数）；length：截取长度（可选，默认截取到末尾）

**功能**：截取指定位置、指定长度的字符串

**示例**：`SELECT SUBSTRING('abcdef',2,3);` -- 结果：bcd

### 4. LEFT() / RIGHT() 左右截取

**语法**：LEFT(str,len)  /  RIGHT(str,len)

**参数**：str：目标字符串；len：截取字符数

**功能**：从字符串左侧/右侧截取指定长度字符

**示例**：`SELECT LEFT('13800138000',3);` -- 结果：138

### 5. REPLACE() 字符串替换

**语法**：REPLACE(str,old_str,new_str)

**参数**：str：原字符串；old_str：待替换内容；new_str：新内容

**功能**：全局替换字符串中指定内容

**示例**：`SELECT REPLACE('测试文本','测试','正式');` -- 正式文本

### 6. TRIM() 去空格/指定字符

**语法**：TRIM([rem_str FROM] str)

**参数**：rem_str：可选，需去除的字符（默认空格）；str：目标字符串

**功能**：去除字符串首尾空格或指定字符；LTRIM() 去左空格，RTRIM() 去右空格

**示例**：`SELECT TRIM('  mysql  ');` -- 去除首尾空格

### 7. LENGTH() / CHAR_LENGTH() 长度统计

**语法**：LENGTH(str)  /  CHAR_LENGTH(str)

**参数**：str：目标字符串

**区别**：LENGTH() 统计**字节数**（utf8 中文1字=3字节）；CHAR_LENGTH() 统计**字符数**

**示例**：`SELECT CHAR_LENGTH('MySQL数据库');` -- 7个字符

### 8. UPPER() / LOWER() 大小写转换

**语法**：UPPER(str) 大写  /  LOWER(str) 小写

**功能**：统一字符串大小写，常用于模糊查询匹配

## 二、数值函数

用于数字运算、取整、四舍五入、随机数、绝对值等场景

### 1. ROUND() 四舍五入

**语法**：ROUND(num,decimal)

**参数**：num：目标数字；decimal：保留小数位数（可为0、正数、负数）

**示例**：`SELECT ROUND(3.1415,2);` -- 3.14

### 2. CEIL() / CEILING() 向上取整

**语法**：CEIL(num)

**功能**：无论小数大小，直接向上取整数

**示例**：`SELECT CEIL(3.1);` -- 4

### 3. FLOOR() 向下取整

**语法**：FLOOR(num)

**功能**：无论小数大小，直接向下取整数

**示例**：`SELECT FLOOR(3.9);` -- 3

### 4. ABS() 绝对值

**语法**：ABS(num)

**功能**：返回数字绝对值

### 5. RAND() 随机数

**语法**：RAND([seed])

**参数**：seed：可选随机种子（固定种子则随机数固定）

**功能**：返回 0~1 之间的随机浮点数

**常用场景**：随机排序 `ORDER BY RAND()`

### 6. MOD() 取模（取余）

**语法**：MOD(a,b)

**功能**：返回 a 除以 b 的余数，等价于 a % b

**示例**：`SELECT MOD(10,3);` -- 1

## 三、日期时间函数（高频业务）

用于获取当前时间、日期格式化、时间加减、时间差计算

### 1. NOW() / CURRENT_TIMESTAMP 当前时间

**语法**：NOW()

**功能**：返回当前 **年月日时分秒**（2025-01-01 12:00:00）

### 2. CURDATE() / CURRENT_DATE 当前日期

**语法**：CURDATE()

**功能**：仅返回 **年月日**，无时分秒

### 3. CURTIME() 当前时间

**语法**：CURTIME()

**功能**：仅返回 **时分秒**，无年月日

### **4. DATE_FORMAT() 日期格式化**

**语法**：DATE_FORMAT(date,format)

**参数**：date：日期字段/时间值；format：格式化规则

**常用格式符**：

- %Y：4位年、%m：2位月、%d：2位日
- %H：24小时制、%i：分钟、%s：秒

**示例**：`SELECT DATE_FORMAT(NOW(),'%Y-%m-%d %H:%i:%s');`

### 5. DATE_ADD() 日期加时间

**语法**：DATE_ADD(date,INTERVAL num unit)

**参数**：unit 单位：YEAR/MONTH/DAY/HOUR/MINUTE/SECOND

**示例**：`SELECT DATE_ADD(NOW(),INTERVAL 7 DAY);` -- 7天后

### 6. DATE_SUB() 日期减时间

**语法**：DATE_SUB(date,INTERVAL num unit)

**示例**：`SELECT DATE_SUB(NOW(),INTERVAL 1 MONTH);` -- 1个月前

### 7. DATEDIFF() 计算日期差

**语法**：DATEDIFF(end_date,start_date)

**功能**：返回两个日期的**天数差**，只比较年月日

**示例**：`SELECT DATEDIFF('2025-01-10','2025-01-01');` -- 9

## 四、条件判断函数

用于 SQL 中条件赋值、空值处理、分支判断，替代简单 case 场景

### 1. IF() 条件判断

**语法**：IF(condition,true_val,false_val)

**参数**：condition：判断条件；true_val：条件成立返回值；false_val：不成立返回值

**示例**：`SELECT IF(age>=18,'成年','未成年') FROM user;`

### **2. IFNULL() 空值替换**

**语法**：IFNULL(val,default_val)

**功能**：如果 val 为 NULL，返回默认值，否则返回原值

**示例**：`SELECT IFNULL(score,0) FROM student;` -- 空成绩默认0

### 3. NULLIF() 等值置空

**语法**：NULLIF(val1,val2)

**功能**：val1=val2 则返回 NULL，否则返回 val1

### 4. CASE 多条件分支

**语法**：

```Plain
CASE 
WHEN 条件1 THEN 值1
WHEN 条件2 THEN 值2
ELSE 默认值
END
```

**功能**：多分支复杂条件判断，优先级高于 IF

## 五、聚合函数

**特点**：聚合函数会**自动忽略 NULL 值**，常与 GROUP BY 配合使用

### 1. COUNT() 计数统计

**语法**：COUNT(* / 字段 / 常量)

- COUNT(*)：统计所有行数（包含空值、重复行）
- COUNT(字段)：统计字段**非NULL**的行数
- COUNT(DISTINCT 字段)：统计去重后的非空行数

### 2. SUM() 求和

**语法**：SUM(数值字段)

**功能**：对字段数值求和，忽略 NULL

### 3. AVG() 平均值

**语法**：AVG(数值字段)

**功能**：计算字段平均值，忽略 NULL（不参与计算）

### 4. MAX() / MIN() 最大/最小值

**语法**：MAX(字段) / MIN(字段)

**功能**：获取字段最大值、最小值，支持数值、字符串、日期

## 六、高级常用函数

### 1. DISTINCT 去重

**语法**：DISTINCT 字段1,字段2

**功能**：对查询结果整体去重，多字段则组合去重

### 2. INSTR() 查找字符位置

**语法**：INSTR(str,substr)

**功能**：返回子串在主串中第一次出现的位置，无则返回0

### 3. UUID() 生成唯一ID

**语法**：UUID()

**功能**：生成32位唯一字符串，可作为主键替代自增ID

### 4. IFNULL / COALESCE 空值处理

**拓展**：COALESCE(val1,val2,val3...) 可接收多个参数，从左到右返回第一个非NULL值
