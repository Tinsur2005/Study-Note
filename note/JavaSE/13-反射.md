# 反射

## 一、反射定义 & 学习意义

### 1.1 反射定义

反射（Reflection）是 Java 的动态机制：**编译时无需确定类型，将类信息获取、对象创建、方法调用、字段读写等操作延迟到运行时执行**。

Java 是静态编译型语言，而反射让 Java 拥有了动态特性。反射可以“看透类的所有结构”，类中所有属性、方法（包括 **private 私有**）在反射面前完全透明，均可被获取和调用。

反射机制依托 `java.lang.reflect` 核心包实现，核心支撑类：

- `Class`：类字节码核心类，反射入口
- `Field`：成员属性类
- `Method`：普通方法类
- `Constructor`：构造方法类

通过以上类，可在运行时动态完成：加载类、创建实例、调用方法、读写字段等操作。

### 1.2 为什么要学习反射

**反射、泛型、注解** 是 Java 主流框架的三大核心基石，是进阶开发必备技能。

1. **提升程序扩展性与灵活性** 支持动态加载类、动态调用方法，无需编译期硬编码绑定类，适合插件系统、通用组件开发。
2. **框架底层核心原理** Spring、MyBatis 等主流框架大量依赖反射，实现依赖注入、AOP 切面、ORM 数据映射等核心功能。
3. **读懂开源框架源码** 绝大多数开源框架底层都大量使用反射，掌握反射是阅读、剖析框架源码的基础。
4. **开发通用工具类** 可实现序列化/反序列化工具、注解处理器、配置文件解析器、对象属性拷贝工具等通用功能。

### 1.3 反射的缺点

反射灵活性极强，但存在明显缺陷，禁止滥用，需按需使用。

1. **性能开销大** 反射在运行时动态解析类结构、查找字段和方法，执行效率远高于直接调用，高性能、高并发场景慎用。
2. **编译期检查失效** 编译器无法校验反射代码的类型、方法、参数合法性，所有错误只会在运行时抛出异常，调试成本高。
3. **破坏封装性，存在安全隐患** 可强制访问、修改类的私有属性和方法，打破面向对象封装特性，可能造成数据篡改、安全漏洞。
4. **代码可读性、可维护性差** 反射代码逻辑晦涩，隐藏了类的真实结构，后期维护、迭代难度大。
5. **难以性能优化** 动态运行特性导致 JVM 无法进行编译期静态优化，整体程序优化难度提升。
6. **不利于代码重构** 反射代码常硬编码类名、方法名、字段名，一旦类结构修改，反射代码极易报错，重构成本极高。

**总结**：普通业务代码优先直接调用；框架、通用工具合理使用；高性能、高安全场景尽量规避。

## 二、反射核心原理理解

### 2.1 面向对象抽象类比

面向对象的核心是抽象，反射是对「类本身」的二次抽象，类比如下：

- 众多人类对象 → 抽象为 `Person` 类
- 众多学生对象 → 抽象为 `Student` 类
- 众多 Java 类 → 抽象为 `Class` 类（存储类的全部结构）
- 众多成员属性 → 抽象为 `Field` 类（存储属性修饰符、类型、名称、值）
- 众多构造方法 → 抽象为 `Constructor` 类（存储构造方法修饰符、参数）
- 众多普通方法 → 抽象为 `Method` 类（存储方法修饰符、名称、参数、返回值）

### 2.2 模具思想理解

`Class、Field、Method、Constructor` 均可理解为**模板/模具**：

- `Class` 模具：定义一个类的整体结构
- `Field` 模具：定义单个成员属性的结构
- `Constructor` 模具：定义构造方法的结构
- `Method` 模具：定义普通方法的结构

通过 `Class` 对象，可反向获取类中所有的 `Field、Constructor、Method` 信息，实现动态操作。

## 三、反射四大核心类

### 3.1 Class 类

#### 1. 核心特性

类加载到 JVM 内存后，**一个类有且仅有唯一一份 Class 字节码对象**，所有反射操作都必须基于 Class 对象完成。

#### 2. 获取 Class 对象的 3 种方式

```java
public void testClass() throws ClassNotFoundException {
    // 方式1：Class.forName(全类名) —— 框架最常用，适配配置文件动态加载
    Class<?> clazz1 = Class.forName("com.situ.day15.Student");

    // 方式2：类名.class —— 编译期已知类型，简洁高效
    Class<?> clazz2 = Student.class;

    // 方式3：对象.getClass() —— 已有实例对象时使用
    Student student = new Student();
    Class<?> clazz3 = student.getClass();

    // 验证：同一个类的Class对象完全一致
    System.out.println(clazz1 == clazz2); // true
    System.out.println(clazz1 == clazz3); // true
}
```

### 3.2 Constructor 构造方法类

通过反射获取构造方法，**动态创建类实例**，支持调用私有构造。

| 方法                                                         | 作用                               |
| ------------------------------------------------------------ | ---------------------------------- |
| `Constructor<T> getConstructor(Class ... parameterTypes)`    | 获取指定参数的 **public** 构造函数 |
| `Constructor<?>[] getConstructors()`                         | 获取所有 **public** 的构造函数     |
| `Constructor<T> getDeclaredConstructor(<?>... parameterTypes)` | 获取指定参数的**任意权限**构造函数 |
| `Constructor<?>[] getDeclaredConstructors()`                 | 获取所有构造函数                   |

#### 常用API

- `getModifiers()`：获取成员修饰符的数字编码
- `setAccessible(true)`：暴力破解，开启私有成员访问权限
- `newInstance()`：执行构造方法，创建对象实例

#### 案例1：遍历所有构造方法

```java
public void testConstructor() {
    Class<?> clazz = Student.class;
    // 获取当前类所有权限的构造方法
    Constructor<?>[] constructors = clazz.getDeclaredConstructors();
    for (Constructor<?> constructor : constructors) {
        // 打印构造方法完整信息
        System.out.println(constructor);
        // 打印构造方法全类名
        System.out.println(constructor.getName());
        // 打印修饰符编码（1=public、2=private）
        System.out.println(constructor.getModifiers());
    }
}
```

#### 案例2：反射调用私有构造创建对象

```java
@Test
public void testPrivateConstructor() throws NoSuchMethodException, IllegalAccessException, InvocationTargetException, InstantiationException {
    Class<?> clazz = Student.class;
    // 获取指定参数的私有构造方法
    Constructor<?> constructor = clazz.getDeclaredConstructor(Integer.class, String.class, Integer.class, String.class);
    // 暴力开启访问权限（核心！否则私有成员无法访问）
    constructor.setAccessible(true);
    // 调用私有构造创建实例
    Student student = (Student) constructor.newInstance(1, "zhangsan", 23, "男");
    System.out.println(student);
}
```

### 3.3 Method 普通方法类

动态获取类的普通方法，运行时调用任意方法（含私有方法）。

| 方法签名                                                     | 功能说明                                                     |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| `Method[] getMethods()`                                      | 获取**当前类 + 所有父类**中全部`public`修饰的方法            |
| `Method getMethod(String name, Class<?>... parameterTypes)`  | 根据方法名、参数类型，精准获取**当前类 + 父类**中指定的`public`方法 |
| `Method[] getDeclaredMethods()`                              | 仅获取**当前本类**定义的所有方法，包含`private/protected/default/public`，**不包含父类方法** |
| `Method getDeclaredMethod(String name, Class<?>... parameterTypes)` | 根据方法名、参数类型，精准获取**当前本类**中指定方法，支持私有方法，**不查找父类** |

#### 案例：反射调用 public 方法

```java
@Test
public void testMethod() throws ClassNotFoundException, NoSuchMethodException, IllegalAccessException, InstantiationException, InvocationTargetException {
    // 1. 获取Class字节码对象
    Class<?> clazz = Class.forName("com.situ.day15.Student");
    // 2. 获取无参构造并创建对象
    Constructor<?> constructor = clazz.getConstructor();
    Student student = (Student) constructor.newInstance();
    // 3. 获取指定方法：方法名 + 方法参数类型
    Method setNameMethod = clazz.getMethod("setName", String.class);
    // 4. 反射调用方法：对象实例 + 方法参数
    setNameMethod.invoke(student, "lisi");
    System.out.println(student);
}
```

### 3.4 Field 成员属性类

核心作用：动态获取、修改类的成员变量，支持读写私有属性。

| 方法签名                            | 注释说明                             |
| ----------------------------------- | ------------------------------------ |
| Field getField(String name)         | 获取当前类及父类指定名字 public 属性 |
| Field[] getFields()                 | 获取当前类及父类所有 public 属性     |
| Field getDeclaredField(String name) | 获取当前类指定名字的属性             |
| Field[] getDeclaredFields()         | 获取当前类所有的属性                 |

核心API：

- `field.get(object)`：获取指定对象的属性值
- `field.set(object, value)`：修改指定对象的属性值
- `field.getType()`：获取属性类型

## 四、反射综合实战案例

### 4.1 动态加载数据库驱动

基于接口编程，通过**配置文件**指定实现类，利用反射动态创建对象，无需修改代码即可切换数据库类型。

#### 步骤1：定义数据库接口

```java
public interface IDB {
    // 数据库连接方法
    void getConnection();
}
```

#### 步骤2：编写多个实现类

```java
// MySQL实现类
public class MySql implements IDB {
    @Override
    public void getConnection() {
        System.out.println("MySql 数据库连接成功");
    }
}

// Oracle实现类
public class Oracle implements IDB {
    @Override
    public void getConnection() {
        System.out.println("Oracle 数据库连接成功");
    }
}

// SqlServer实现类
public class SqlServer implements IDB {
    @Override
    public void getConnection() {
        System.out.println("SqlServer 数据库连接成功");
    }
}
```

#### 步骤3：配置文件 db1.properties

```properties
className=com.situ.day15.MySql
```

#### 步骤4：反射动态加载实现类

```java
public class DBDemo {
    public static void main(String[] args) throws IOException, ClassNotFoundException, NoSuchMethodException, InvocationTargetException, InstantiationException, IllegalAccessException {
        // 1. 获取类加载器
        ClassLoader classLoader = DBDemo.class.getClassLoader();
        // 2. 读取配置文件
        InputStream inputStream = classLoader.getResourceAsStream("db1.properties");
        Properties properties = new Properties();
        properties.load(inputStream);
        // 3. 获取配置文件中的全类名
        String className = properties.getProperty("className");
        // 4. 反射创建实例并调用方法
        Class<?> clazz = Class.forName(className);
        Constructor<?> constructor = clazz.getConstructor();
        IDB db = (IDB) constructor.newInstance();
        db.getConnection();
    }
}
```

> **优点**：切换数据库只需修改配置文件，无需改动业务代码，符合开闭原则。

### 4.2 批量替换对象String属性内容

编写通用方法，传入任意对象，自动将对象中所有 String 类型属性的字符 `a` 替换为 `b`，体现反射的动态通用性。

#### 步骤1：测试实体类

```java
public class Teacher {
    private String name = "android";
    private int age = 18;
    private String address = "qingdao";

    @Override
    public String toString() {
        return "Teacher [name=" + name + ", age=" + age + ", address=" + address + "]";
    }
}
```

#### 步骤2：反射通用修改方法

```java
@Test
public void testFieldUpdate() throws IllegalAccessException {
    // 测试Teacher对象
    Teacher teacher = new Teacher();
    System.out.println("修改前：" + teacher);
    changeField(teacher);
    System.out.println("修改后：" + teacher);

    // 测试Student对象（任意对象均可适配）
    Student student = new Student();
    student.setName("lisia");
    System.out.println("修改前：" + student);
    changeField(student);
    System.out.println("修改后：" + student);
}

/**
 * 通用反射方法：将任意对象的所有String属性中a替换为b
 */
private void changeField(Object object) throws IllegalAccessException {
    // 1. 获取目标对象的Class字节码
    Class<?> clazz = object.getClass();
    // 2. 获取所有属性（含私有）
    Field[] fields = clazz.getDeclaredFields();
    // 3. 遍历所有属性
    for (Field field : fields) {
        // 只处理String类型属性
        if (field.getType() == String.class) {
            // 暴力解除私有访问限制（解决IllegalAccessException）
            field.setAccessible(true);
            // 获取原有属性值
            String oldValue = (String) field.get(object);
            if (oldValue != null && !"".equals(oldValue)) {
                // 字符替换
                String newValue = oldValue.replace("a", "b");
                // 重新赋值
                field.set(object, newValue);
            }
        }
    }
}
```

#### 运行结果

```bash
修改前：Teacher [name=android, age=18, address=qingdao]
修改后：Teacher [name=bndroid, age=18, address=qingdbo]
修改前：Student{name='lisia', age=null, gender='null'}
修改后：Student{name='lisib', age=null, gender='null'}
```
