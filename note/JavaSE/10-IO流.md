# IO流

## 一、IO流核心基础介绍

### 1.1 IO基本定义

IO 全称 Input（输入）、Output（输出），主要用于实现程序与外部设备之间的数据传输。

**流（Stream）**：流是一组有顺序的，有起点和终点的字节集合，是对数据传输的总称或抽象。即数据在两设备间的传输称为流，流的本质是数据传输，根据数据传输特性将流抽象为各种类，方便更直观的进行数据操作。

### 1.2 IO流的分类

Java IO流主要从**数据传输单位**和**数据传输方向**两个维度划分，所有IO流的父类均为抽象类，无法直接实例化。

#### 1.  按数据类型划分

##### 字节流

- 操作单位：以 **字节（byte）** 为最小读写单位
- 适用场景：支持所有类型文件，包括图片、视频、音频、压缩包、二进制文件、文本文件等
- 核心特点：底层直接操作二进制数据，**不自动处理字符编码**
- 命名规范：所有字节流类以 `InputStream`、`OutputStream` 结尾
- 常用子类：`FileInputStream`、`FileOutputStream`

##### 字符流

- 操作单位：以 **字符（char）** 为最小读写单位
- 适用场景：仅适用于**纯文本文件**（txt、java、md等）
- 核心原理：底层基于字节流实现，额外封装了**自动编码/解码**功能（支持UTF-8、GBK等编码格式），可简单理解为：**字符流 = 字节流 + 编码处理**
- 命名规范：所有字符流类以 `Reader`、`Writer` 结尾
- 常用子类：`FileReader`、`FileWriter`

> 非文本文件（图片/视频/压缩包）**必须使用字节流**，使用字符流会导致文件乱码、损坏；纯文本文件优先使用字符流，可自动处理编码问题，操作更便捷。

#### 2. 按数据流向划分

按数据流向划分是相对程序来说的：

- **输入流**：外部设备（文件、网络）→ 程序，负责读取数据，父类为 `InputStream`、`Reader`
- **输出流**：程序 → 外部设备（文件、网络），负责写入数据，父类为 `OutputStream`、`Writer`

## 二、字符流

字符流专门用于文本文件读写，核心分为 **文件字符输入流（FileReader）** 和 **文件字符输出流（FileWriter）**。

### 2.1 单字符读取

单次读取单个字符，返回字符对应的int数值，读取到文件末尾时返回 **-1**，适合小文件演示，效率较低。

```java
@Test
public void test1() {
    try {
        FileReader fileReader = new FileReader("IO.txt");
        int ch1 = fileReader.read();
        System.out.println((char)ch1);//a
        int ch2 = fileReader.read();
        System.out.println((char)ch2);//b
        int ch3 = fileReader.read();
        System.out.println((char)ch3);//c
        int ch4 = fileReader.read();
        System.out.println(ch4);//-1  文件读取完毕标志
    } catch (FileNotFoundException e) {
        e.printStackTrace();
    } catch (IOException e) {
        e.printStackTrace();
    }
}
```

### 2.2 循环读取

通过while循环持续读取文件内容，直到读取到末尾（返回-1），替代手动多次read，适配任意大小文本文件。

```java
@Test
public void test1() {
    try {
        FileReader fileReader = new FileReader("IO.txt");
        int ch = fileReader.read();
        while(ch != -1){
            System.out.print((char)ch);
            ch = fileReader.read();
        }
    } catch (FileNotFoundException e) {
        throw new RuntimeException(e);
    } catch (IOException e) {
        throw new RuntimeException(e);
    }
}
```

### 2.3 字符数组缓冲区读取

自定义字符数组作为缓冲区，一次性读取多个字符，减少IO交互次数，大幅提升读取效率，是开发常用写法。

```java
@Test
public void test2(){
    try {
        FileReader fileReader = new FileReader("IO.txt");
        char[] chs = new char[1024];
        int len = fileReader.read(chs);
        while(len != -1){
            System.out.print(new String(chs,0,len));
            len = fileReader.read(chs);
        }
    } catch (FileNotFoundException e) {
        throw new RuntimeException(e);
    } catch (IOException e) {
        throw new RuntimeException(e);
    }
}
```

### 2.4 字符流实现文本文件复制

通过 `FileReader` 读取原文本和通过`FileWriter` 写入新文件，实现文件复制，读取多少、写入多少。

```java
@Test
public void testFileReaderWriter(){
    FileReader fileReader = null;
    FileWriter fileWriter = null;
    try {
        char[] chs = new char[10];
        fileReader = new FileReader("IO.txt");
        fileWriter = new FileWriter("IO_Write.txt");
        int len = -1;
        while((len = fileReader.read(chs)) != -1){
            fileWriter.write(chs , 0 , len);
        }
    } catch (FileNotFoundException e) {
        throw new RuntimeException(e);
    } catch (IOException e) {
        throw new RuntimeException(e);
    } finally{
        if(fileReader != null){
            try {
                fileReader.close();
            } catch (IOException e) {
                throw new RuntimeException(e);
            }
        }

        if(fileWriter != null){
            try {
                fileWriter.close();
            } catch (IOException e) {
                throw new RuntimeException(e);
            }
        }
    }
}
```

## 三、字节流

字节流是通用文件流，支持所有文件类型读写，尤其适用于图片、视频、音频、压缩包等二进制文件，开发中多用于文件复制、传输。

使用 `FileInputStream` 读取二进制文件和使用`FileOutputStream` 写入新文件和上文中的通过 `FileReader` 读取原文本和通过`FileWriter` 写入新文件**流程上完全一致**，只更改了**部分方法名和类名**。

```java
@Test
public void testFileInputStream(){
    FileInputStream fileInputStream = null;
    FileOutputStream fileOutputStream = null;
    try {
        fileInputStream = new FileInputStream("demo.png");
        fileOutputStream = new FileOutputStream("demo_Write.png");
        int len = -1;
        byte[] bytes = new byte[1024];
        while((len = fileInputStream.read(bytes)) != -1){
            fileOutputStream.write(bytes,0,len);
        }

    } catch (IOException e) {
        throw new RuntimeException(e);
    } finally {
        if(fileInputStream != null){
            try {
                fileInputStream.close();
            } catch (IOException e) {
                throw new RuntimeException(e);
            }
        }
        if(fileOutputStream != null){
            try {
                fileOutputStream.close();
            } catch (IOException e) {
                throw new RuntimeException(e);
            }
        }
    }
}
```

## 四、对象流

### 4.1 概念

**对象流：**专门用于读写Java对象的特殊IO流，核心类为 `ObjectInputStream`、`ObjectOutputStream`

**序列化：**通过 `ObjectOutputStream` 将Java对象写入文件（对象持久化存储）

**反序列化：**通过 `ObjectInputStream` 从文件中读取并还原Java对象

> 需要序列化的实体类，必须实现 `Serializable` 接口，否则抛出异常：`java.io.NotSerializableException`。该接口无任何抽象方法，仅用于标记类可被序列化。

### 4.2 序列化

```java
@Test
public void testObjectOutputStream(){
    Student student = new Student(31,"张三","男",18);
    ObjectOutputStream objectOutputStream = null;
    FileOutputStream fileOutputStream = null;
    try {
        fileOutputStream = new FileOutputStream("stu");
        objectOutputStream = new ObjectOutputStream(fileOutputStream);
        objectOutputStream.writeObject(student);
    } catch (FileNotFoundException e) {
        throw new RuntimeException(e);
    } catch (IOException e) {
        throw new RuntimeException(e);
    } finally {
        if(objectOutputStream != null){
            try {
                objectOutputStream.close();
            } catch (IOException e) {
                throw new RuntimeException(e);
            }
        }
        if(fileOutputStream != null){
            try {
                fileOutputStream.close();
            } catch (IOException e) {
                throw new RuntimeException(e);
            }
        }
    }
}
```

### 4.3 反序列化

```java
@Test
public void testObjectInputStream(){
    FileInputStream fileInputStream = null;
    ObjectInputStream objectInputStream = null;
    try {
        fileInputStream = new FileInputStream("stu");
        objectInputStream = new ObjectInputStream(fileInputStream);
        Student student = (Student) objectInputStream.readObject();
        System.out.println(student);
    } catch (FileNotFoundException e) {
        throw new RuntimeException(e);
    } catch (IOException e) {
        throw new RuntimeException(e);
    } catch (ClassNotFoundException e) {
        throw new RuntimeException(e);
    } finally {
        if(objectInputStream != null){
            try {
                objectInputStream.close();
            } catch (IOException e) {
                throw new RuntimeException(e);
            }
        }
        if (fileInputStream != null){
            try {
                fileInputStream.close();
            } catch (IOException e) {
                throw new RuntimeException(e);
            }
        }
    }
}
```

## 五、规范与注意事项

### 5.1 流关闭顺序规范

1. **通用规则**：先打开的流后关闭，后打开的流先关闭
2. **嵌套流（包装流）规则**：根据依赖关系关闭，高层包装流依赖底层文件流，**先关闭包装流，再关闭底层流**
3. 所有流资源必须手动关闭，否则会占用操作系统IO资源，导致资源泄露
4. 流关闭操作必须放在 `finally` 代码块，保证程序异常时资源仍能释放

### 5.2 字节流与字符流注意事项

1. 图片、视频、音频、压缩包等二进制文件，**只能使用字节流**，字符流会损坏文件
2. txt、java等纯文本文件，优先使用字符流，自动处理编码，避免乱码问题
3. 字符数组/字节数组读写时，必须指定有效长度（write(buffer,0,length)），禁止直接写入完整数组，避免读取末尾空数据、脏数据

### 5.3 对象流序列化核心注意点

1. 序列化实体类必须实现`Serializable` 接口，否则序列化失败
2. 反序列化时，项目中必须存在对应实体类，否则抛出 `ClassNotFoundException`
