# 集合框架

## 一、集合框架概述

### 1.1 什么是集合

Java 集合是用于**存储、操作一组对象**的工具类，属于 java.util 包，替代了数组的部分短板。数组长度固定、只能存储固定类型数据，而集合**长度可变、可存储任意对象、提供丰富的增删改查和批量操作方法**。

### 1.2 集合整体架构（两大派系）

Java 集合框架核心分为 **Collection（单列集合）** 和 **Map（双列集合）** 两大根接口：

- **Collection**：单列集合，每次存储一个元素        
  - List：**有序（放进去顺序和拿出来顺序一致）、可重复**
  - Set：**无序（放进去顺序和拿出来顺序不一定一致）、不可重复**
- **Map**：双列集合，每次存储一对元素（**Key-Value 键值对**）
  - Key：唯一、无序、不可重复
  - Value：可重复、无序

### 1.3 核心继承关系简图

Collection 接口 → List/Set 子接口 → 具体实现类 Map 接口 → HashMap/LinkedHashMap/TreeMap 等实现类

常用实现类总结：

- List：ArrayList、LinkedList
- Set：HashSet、LinkedHashSet、TreeSet
- Map：HashMap、LinkedHashMap、TreeMap、HashTable

### 1.4 示例

```java
@Test
public void test1(){
    Student[] students = new Student[3];//数组的局限性

    //泛型
    ArrayList<Student> list = new ArrayList<>();
    //有序可重复
    Student student1 = new Student(1, "张三1", 18);
    Student student2 = new Student(2, "张三2", 18);
    Student student3 = new Student(3, "张三3", 18);
    Student student4 = new Student(4, "张三4", 18);
    list.add(student1);
    list.add(student2);
    list.add(student3);
    list.add(student4);

    for (Student student : list){
        System.out.println(student);
    }

    System.out.println("------------");

    HashSet<Student> set = new HashSet<>();
    //无序不重复
    //无序：放进去顺序和拿出来的顺序可能是不一致的
    set.add(student1);
    set.add(student2);
    set.add(student3);
    set.add(student4);

    for (Student student : set){
        System.out.println(student);
    }
}
```

## 二、Collection 通用方法

Collection 是所有单列集合的父接口，定义了所有 List、Set通用的核心方法：

| 方法                         | 作用                 |
| :--------------------------- | :------------------- |
| boolean add(E e)             | 添加单个元素         |
| boolean remove(Object o)     | 删除指定元素         |
| boolean contains(Object o)   | 判断是否包含指定元素 |
| int size()                   | 获取集合元素个数     |
| boolean isEmpty()            | 判断集合是否为空     |
| void clear()                 | 清空集合所有元素     |
| Object[] toArray()           | 集合转数组           |
| boolean addAll(Collection c) | 批量添加集合元素     |

## 三、List 有序可重复集合

### 3.1 List 集合特点

- 元素**有序**：存储顺序和取出顺序一致，拥有索引
- 元素**可重复**：允许存储相同元素
- 支持索引操作：可通过下标精准增删改查

### 3.2 ArrayList和LinkedList 对比

#### 1. ArrayList

- **底层结构**：动态扩容数组
- **特点**：查询快、增删慢；线程不安全、效率高
- **扩容机制**：初始容量10，扩容为原容量的1.5倍
- **适用场景**：大量查询、少量增删的业务场景

#### 2. LinkedList

- **底层结构**：双向链表
- **特点**：增删快、查询慢；线程不安全、效率高
- **优势**：无需扩容，新增/删除元素仅修改节点指针
- **适用场景**：大量增删、少量查询，适合实现栈、队列

>LinkedList可以间接实现一个**队列（FIFO先进先出）**
>
>```java
>public void test2(){
>    LinkedList linkedList = new LinkedList<>();
>    linkedList.addLast("A");
>    linkedList.addLast("B"); //在尾部添加
>    linkedList.addLast("C"); 
>
>    linkedList.removeFirst();//在头部移除
>
>    System.out.println(linkedList);
>}
>```

### 3.3 List 特有方法
基于索引的专属方法：get(int index)、set(int index,E e)、add(int index,E e)、remove(int index)

## 四、Set 无序不可重复集合

### 4.1 Set 集合特点

- 元素**无序**：存储顺序和取出顺序不一致，无索引
- 元素**不可重复**：自动去重，不允许存储相同元素
- 无索引：不支持普通for循环遍历，只能迭代器/增强for

### 4.2 三大常用实现类对比

#### 1. HashSet

- **底层结构**：哈希表（数组+链表+红黑树，JDK1.8）
- **特点**：存取速度快、完全无序、去重
- **去重原理**：依赖 hashCode() + equals() 方法        
  - 先判断两个元素 hashCode 值是否相同
  - 不同：直接存储；相同：再调用 equals() 比较内容
  - equals 返回 true：判定重复，不存储；false：存储
- **注意**：自定义对象存 HashSet，必须重写 hashCode 和 equals 方法

#### 2. LinkedHashSet

- **底层结构**：哈希表 + 双向链表
- **特点**：**有序（存取顺序一致）**、不可重复
- **原理**：双向链表记录元素存储顺序，哈希表保证唯一性
- **适用场景**：需要去重且保留存储顺序的场景

#### 3. TreeSet

- **底层结构**：红黑树（平衡二叉树）
- **特点**：**自然排序**、不可重复、无序（非存取序，是大小序）
- **排序规则**：        
  - 自然排序：元素实现 Comparable 接口，重写 compareTo 方法
  - 比较器排序：创建 TreeSet 时传入 Comparator 比较器
- **适用场景**：需要自动排序+去重的场景

## 五、Map 双列键值对集合

### 5.1 Map 集合特点

- 存储 **Key-Value 键值对**，一一对应关系
- Key：唯一、无序、不可重复（Set 特性）
- Value：可重复、无序
- 一个 Key 只能对应一个 Value，重复 Key 会覆盖原有 Value

```java
@Test
public void test3(){
    Map<String , String> map = new HashMap<>();
    map.put("cn" , "中国");
    map.put("us" , "美国");
    map.put("uk" , "英国");

    String value1 = map.get("cn");
    System.out.println(value1);
    String value2 = map.get("us");
    System.out.println(value2);
}
```

### 5.2 常用实现类对比

#### 1. HashMap（重点）

- **底层结构**：哈希表（数组+链表+红黑树）
- **特点**：查询存取效率极高、线程不安全、允许 null 键和 null 值
- **阈值规则**：链表长度>8 且数组长度≥64，转为红黑树；链表长度≤6，退回链表
- **初始容量**16，加载因子0.75，扩容为2倍
- **适用场景**：绝大多数键值对存储场景（日常开发首选）

#### 2. LinkedHashMap

- **底层结构**：HashMap + 双向链表
- **特点**：**有序（存取顺序一致）**、去重、线程不安全
- **适用场景**：需要保留键值对存储顺序的场景，可实现 LRU 缓存

#### 3. TreeMap

- **底层结构**：红黑树
- **特点**：按键大小自动排序、线程不安全
- **排序方式**：自然排序、比较器排序，和 TreeSet 一致

## 六、集合遍历方式

### 6.1 List 遍历方式

1. **普通 for 循环**：通过索引遍历，适合 List
2. **增强 for 循环**：简洁高效，无索引，适合所有集合
3. **迭代器 Iterator**：集合通用遍历，支持遍历中删除元素
4. **forEach 流式遍历（JDK8+）**：极简写法

### 6.2 Set 遍历方式（暂时了解）

无索引，不支持普通for循环，仅支持：增强for、迭代器、forEach

### 6.3 Map 遍历方式

#### **1. entrySet() 遍历（常用）**

直接获取键值对对象，效率最高

```java
@Test
public void test3(){
    Map<String , String> map = new HashMap<>();
    map.put("cn" , "中国");
    map.put("us" , "美国");
    map.put("uk" , "英国");

    Set<Map.Entry<String , String>> entrySet = map.entrySet();
    for (Map.Entry<String , String> entry : entrySet){
        System.out.println(entry.getKey() + " : " + entry.getValue());
    }
}
```

#### 2. keySet() 遍历

先获取键，再通过键取值，效率比较一般

```java
    @Test
    public void test5(){
        Map<String , String> map = new HashMap<>();
        map.put("cn" , "中国");
        map.put("us" , "美国");
        map.put("uk" , "英国");

        Set<String> keySet = map.keySet();
        for(String key : keySet){
            System.out.println(map.get(key));
        }
    }
```

#### 3. 迭代器遍历

```java
@Test
public void test4(){
    Map<String , String> map = new HashMap<>();
    map.put("cn" , "中国");
    map.put("us" , "美国");
    map.put("uk" , "英国");

    Set<Map.Entry<String , String>> entrySet = map.entrySet();
    Iterator<Map.Entry<String , String>> iterator = map.entrySet().iterator();
    while (iterator.hasNext()){ //hasNext() 判断有没有下一个
        Map.Entry<String , String> entry = iterator.next();
        System.out.println(entry.getKey() + " : " + entry.getValue());
    }

}
```
