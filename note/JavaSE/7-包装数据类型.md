# 包装数据类型

## 一、概述

Java 语言为8种**基本数据类型**分别提供了对应的**包装类（引用类型）**。

基本类型是简单数据类型，不具备对象特性，无法调用方法、无法参与泛型、无法赋值为 null；而包装类将基本数据类型封装为对象，补齐了基本类型的短板，是 Java 面向对象特性的重要补充。

**核心作用**：

- 将基本类型转为对象，适配集合、泛型（集合只能存储引用类型）
- 提供大量数值转换、字符串转换、数值判断的工具方法
- 支持赋值 **null**，可用于标识数据缺失场景

## 二、基本类型与包装类对应关系

8种基本类型对应8个包装类，其中 `int`、`char` 包装类名称特殊，其余均为首字母大写即可：

| 基本数据类型 | 包装类（引用类型） |
| :----------- | :----------------- |
| byte         | Byte               |
| short        | Short              |
| int          | Integer（特殊）    |
| long         | Long               |
| float        | Float              |
| double       | Double             |
| char         | Character（特殊）  |
| boolean      | Boolean            |

所有包装类均位于 `java.lang` 包下，无需手动导入，直接使用。

## 三、手动装箱和手动拆箱

这是开发最常用的核心知识点，所有数值型包装类转换规则一致。

### 1. 手动装箱

即实现基本类型 → 包装类

通过包装类构造方法 / `valueOf()` 方法实现：

```java
Integer num2 = Integer.valueOf(20);
```

### 2.手动拆箱

即实现包装类 → 基本类型

通过包装类的 `xxxValue()` 方法：

```java
Integer num = Integer.valueOf(30);
int a = num.intValue(); // 转为int基本类型
```

## 四、自动装箱与自动拆箱

JDK5 引入自动转换机制，编译器自动完成基本类型与包装类的转换，无需手动调用方法。

### 1. 自动装箱

基本类型自动转为对应包装类对象：

```java
Integer a = 10; 
// 编译器自动编译为：Integer a = Integer.valueOf(10);
```

### 2. 自动拆箱

包装类对象自动转为基本类型：

```java
int b = a;
// 编译器自动编译为：int b = a.intValue();
```

## 五、包装数据类型和字符串之间的转换

### 1.基本数据类型转换成字符串

(1) 基本数据类型+"" ：


```java
String str = 12 + ""; // "12"
```

(2) 基本数据类型的包装类.toString()：

```java
String str1 = Integer.toString(3);// "3"
String str2 = Double.toString(3.14);// "3.14"
```

### 2.字符串转换成基本数据类型

**(1)使用Xxxx.parseXxx()方法：**

```java
Integer.parseInt(String str);  // "23"  
Double.parseDouble(String str);  //"3.14"
Boolean.parseBoolean(String str);//"true"
Xxxx.parseXxx(String str);
```

(2) new对象： 

```java
Integer integer = Integer.valueOf(String str);
Integer interger = Integer.valueOf("4");
int i = integer.intValue();
```
