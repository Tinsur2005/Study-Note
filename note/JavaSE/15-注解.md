# 注解

## 一、定义和作用

### 1.1 什么是注解

注解（Annotation）是 **Java 5.0** 版本开始引入的核心新特性，可看作一种**特殊的标记式注释**，专门用于修饰类、方法、成员变量、参数、构造器等Java元素。

注解本身不具备业务逻辑，仅用于为程序提供附加描述信息，供编译器或运行时程序解析使用。

Java 注解分为两类：

- **内置注解**：JDK 原生提供，如`@Override`、`@WebServlet`、`@Deprecated` 等
- **自定义注解**：开发者根据业务需求自行定义的注解

### 1.2 注解的解析方式

注解必须被解析后才能生效，Java 中注解的解析方式分为两种：

#### 1. 编译期扫描解析

编译器在代码编译阶段扫描注解并完成校验、处理，仅作用于编译阶段，运行阶段失效。

**典型案例**：`@Override`

编译时编译器会校验当前方法是否真正重写了父类的对应方法，若方法名、参数列表、返回值不符合重写规则，直接编译报错。

```java
// 重写父类toString方法，编译期自动校验重写合法性
@Override
public String toString() {
    return super.toString();
}
```

#### 2. 运行期反射解析

注解保留至程序运行阶段，通过**Java反射机制**获取注解信息并完成业务处理，是框架开发的核心底层原理，例如 Spring 框架的`@Component`、`@Value`，Web 框架的 `@WebServlet` 等。

```java
// 运行时通过反射解析该注解，注册Servlet路由
@WebServlet("/student")
public class StudentServlet extends HttpServlet {
}
```

### 1.3 注解的核心作用

1. **指导编译器编译**：告知编译器代码校验规则、编译行为（如 `@Override` 校验重写、`@SuppressWarnings` 抑制警告）；
2. **简化项目配置**：替代传统繁琐的 XML 配置文件，实现**注解式配置**，精简代码、提升开发效率，是主流框架的核心设计思想。

## 二、自定义注解

Java 允许开发者自定义注解，用于为类、字段、方法、参数等元素添加自定义描述信息，结合反射可实现自定义业务逻辑处理。

**语法**：使用 `@interface` 关键字定义自定义注解

### 2.1 元注解（注解的注解）

**元注解**：专门用于修饰自定义注解的注解，作用是**限制自定义注解的作用范围、生命周期**，是自定义注解的基础。Java 提供4种核心元注解，核心常用两种如下：

#### 1. @Target：指定注解的作用范围

用于限定自定义注解可以修饰的Java元素，可指定单个或多个范围。

| 取值                       | 作用范围说明          |
| :------------------------- | :-------------------- |
| ElementType.TYPE           | 作用于 类、接口、枚举 |
| ElementType.FIELD          | 作用于 成员字段/属性  |
| ElementType.METHOD         | 作用于 方法           |
| ElementType.PARAMETER      | 作用于 方法参数       |
| ElementType.CONSTRUCTOR    | 作用于 构造方法       |
| ElementType.LOCAL_VARIABLE | 作用于 局部变量       |

#### 2. @Retention：指定注解的生命周期

用于限定自定义注解的存活阶段，决定注解在哪个阶段可被解析，包含3个级别（优先级逐级升高）。

| 取值                    | 生命周期说明                                               | 使用场景                     |
| :---------------------- | :--------------------------------------------------------- | :--------------------------- |
| RetentionPolicy.SOURCE  | 仅源码阶段有效，编译后丢弃，不存入字节码文件               | 编译期校验注解，如 @Override |
| RetentionPolicy.CLASS   | 默认值，编译后存入字节码文件，运行阶段丢弃，无法被反射获取 | 基础编译增强注解             |
| RetentionPolicy.RUNTIME | 源码、字节码、运行阶段均有效，**可通过反射获取注解信息**   | 框架自定义注解（核心常用）   |

### 2.2 自定义注解完整案例

#### 1. 定义自定义注解

定义 `@Author` 注解，可作用于类、字段、方法，保留至运行阶段，支持默认值、数组属性。

```java
import java.lang.annotation.ElementType;
import java.lang.annotation.Retention;
import java.lang.annotation.RetentionPolicy;
import java.lang.annotation.Target;

/**
 * 自定义注解：作者信息注解
 * 可作用于类、字段、方法，运行时有效，支持反射解析
 */
@Target({ElementType.METHOD, ElementType.FIELD, ElementType.TYPE})
@Retention(RetentionPolicy.RUNTIME)
public @interface Author {
    // 普通属性，无默认值，使用时必须赋值
    String name() default "";

    // 带默认值的属性，使用时可省略赋值，自动使用默认值20
    int age() default 20;

    // 特殊value属性：注解仅有value一个属性时，使用时可省略属性名
    String[] value() default {};
}
```

#### 2. 使用自定义注解

在类、成员字段、方法上使用 `@Author` 注解，演示不同赋值方式。

> 当注解中**只有value一个属性**时，使用注解可直接传值，省略 `value=`

```java
import org.junit.Test;
import java.lang.reflect.Method;
import java.util.Arrays;

/**
 * 自定义注解测试类
 */
@Author(name = "zhao", age = 12, value = "男")
public class AuthorDemo {

    // 省略所有属性，自动使用默认值
    @Author
    private String str;

    // 多属性赋值，value传入数组
    @Author(name = "zhangsan", age = 23, value = {"男", "女"})
    public void add() {
    }

    /**
     * 反射解析自定义注解测试方法
     */
    @Test
    public void test1() throws NoSuchMethodException {
        // 1. 获取当前类的Class对象
        Class<AuthorDemo> clazz = AuthorDemo.class;

        // 2. 解析类上的@Author注解
        Author typeAuthor = clazz.getAnnotation(Author.class);
        System.out.println("类注解-value：" + typeAuthor.value()[0]);
        System.out.println("类注解-完整value数组：" + Arrays.toString(typeAuthor.value()));

        // 3. 反射获取指定方法对象
        Method method = clazz.getDeclaredMethod("add");
        // 4. 解析方法上的@Author注解
        Author methodAuthor = method.getAnnotation(Author.class);

        // 5. 获取注解属性值并打印
        System.out.println("方法注解-name：" + methodAuthor.name());    // zhangsan
        System.out.println("方法注解-age：" + methodAuthor.age());      // 23
        System.out.println("方法注解-value：" + Arrays.toString(methodAuthor.value())); // [男, 女]
    }
}
```

### 2.3 注解使用核心规则

1. 自定义注解通过 `@interface` 定义，注解中的「属性」本质是抽象方法；
2. 通过 `default` 关键字为属性设置默认值，使用注解时可省略该属性赋值；
3. 当注解中**只有value一个属性**时，使用注解可直接传值，省略 `value=`；
4. 需运行时解析的注解，必须设置 `@Retention(RetentionPolicy.RUNTIME)`，否则反射无法获取；
5. 通过 `Class`、`Method`、`Field` 等反射对象的 `getAnnotation()` 方法获取注解实例。
