# 泛型

## 一、泛型定义 & 基本使用

### 1.1 核心概述

泛型是 **JDK 1.5 新增特性**，核心作用：

- **编译期类型检查**：在编译阶段校验数据类型，避免类型不匹配问题
- **避免强制类型转换**：获取数据时无需手动强转，简化代码、减少报错

### 1.2 无泛型的问题演示

未使用泛型时，集合可以存储任意类型数据，取值必须强制转换，极易出现类型转换异常。

```java
@Test
public void testGeneric() throws Exception {
    // 无泛型集合，默认存储Object类型
    ArrayList list = new ArrayList();
    list.add("China");
    list.add(1); // 可以存入任意类型数据，编译不报错

    // 取值需要强制类型转换，存在类型转换风险
    String str = (String) list.get(0);
}
```

### 1.3 泛型基础使用

声明集合时指定具体元素类型，编译期会校验存入数据的类型，取值直接返回指定类型，无需强转。

```java
@Test
public void testGeneric2() throws Exception {
    // 指定集合元素类型为String
    ArrayList<String> list = new ArrayList<String>();
    list.add("China");
    // list.add(1); // 编译报错！泛型限制只能存入String类型

    // 直接获取String类型，无需强制转换
    String str = list.get(0);
}
```

### 1.4 语法规则

```java
@Test
public void test3() {
    // 1. 前后泛型类型一致（标准写法）
    List<Object> list1 = new ArrayList<Object>();
    List<String> list2 = new ArrayList<String>();

    // 2. JDK1.7+ 右侧泛型可省略（菱形语法）
    List<String> list3 = new ArrayList<>();

    // 3. 仅右侧写泛型无效，等价于无泛型集合
    List list4 = new ArrayList<String>();
    list4.add(1); // 可存入任意类型，泛型失效

    // 4. 前后泛型类型不一致，编译报错
    // List<Object> list5 = new ArrayList<String>();

    // 5. 泛型仅支持引用类型，不支持基本数据类型
    // List<int> list6 = new ArrayList<>(); // 编译报错
}
```

**核心规则总结**：

- 泛型必须为**引用数据类型**（包装类、对象、集合等）
- 左侧声明泛型类型才生效，仅右侧声明无效
- JDK1.7 支持菱形语法，简化右侧泛型书写

## 二、泛型擦除

### 2.1 核心概念

泛型 **仅在编译时期有效**，Java 编译器编译代码后，会自动擦除所有泛型信息，最终生成的字节码文件中不存在泛型。

### 2.2 泛型擦除的意义

- 编译期校验类型，帮助开发者编写规范代码，规避类型错误
- 保证 JVM 向下兼容，低版本 JDK 可正常运行高版本带泛型的代码

```java
@Test
public void testGenericErase() {
    List<String> list1 = new ArrayList<String>();
    List<Integer> list2 = new ArrayList<Integer>();
    // 获取集合的Class对象
    Class c1 = list1.getClass();
    Class c2 = list2.getClass();
    // 输出true，证明运行时无泛型区分
    System.out.println(c1 == c2); 
}
```

**结论**：运行时 `ArrayList<String>` 和 `ArrayList<Integer>` 本质都是 `ArrayList` 类型，泛型信息已被擦除。

## 三、泛型方法 / 泛型类 / 泛型接口

抽取通用业务逻辑，编写复用性极高的类和方法，解除类型固定限制，让程序更灵活、通用性更强。

### 3.1 泛型方法

方法独立声明泛型，调用方法时动态确定泛型类型，灵活适配不同参数返回值类型。

```java
public class GenericDemo2 {
    // 普通方法，类型固定，复用性差
    public Student add1(Student student, Teacher teacher) {
        return null;
    }

    // 泛型方法：<K,T> 声明泛型标识，K为返回值类型，K/T为参数类型
    public <K,T> K add(K k, T t) {
        return k;
    }

    @Test
    public void test1() {
        // 调用时自动确定泛型类型
        Float result1 = add(1.0f, 1);
        System.out.println(result1);

        String result2 = add("abc", 1);
        System.out.println(result2);
    }
}
```

### 3.2 泛型类

在类上声明泛型，类中所有方法、属性可直接使用该泛型，无需单个方法重复声明，适合通用工具类、DAO层通用操作类。

```java
// 泛型类：声明通用类型T
public class BaseDao <T>{
    // 成员变量使用泛型
    private List<T> list = new ArrayList<>();
    
    // 通用新增方法
    public void add(T t) {}
    
    // 通用修改方法
    public void update(T t) {}
    
    // 通用查询方法
    public T selectById(Integer id) {
        return null;
    }
}

// 测试泛型类
@Test
public void test2() {
    // 绑定Student类型，操作学生数据
    Student student = new Student();
    BaseDao<Student> baseDao1 = new BaseDao<>();
    baseDao1.add(student);
    baseDao1.update(student);
    Student student1 = baseDao1.selectById(1);

    // 绑定Teacher类型，操作教师数据
    Teacher teacher = new Teacher();
    BaseDao<Teacher> baseDao2 = new BaseDao<>();
    baseDao2.add(teacher);
    baseDao2.update(teacher);
    Teacher teacher1 = baseDao2.selectById(1);
}
```

### 3.3 泛型接口

在接口上声明泛型，**实现类确定具体泛型类型**，常用于统一业务层、DAO层接口规范。

```java
// 泛型接口
public interface IBaseDao<T> {
    void add(T t );
    void update(T t );
}

// 实现类指定泛型为Person
public class PersonDao implements IBaseDao<Person> {
    @Override
    public void add(Person person) {}

    @Override
    public void update(Person person) {}
}

// 实现类指定泛型为Student
public class StudentDao implements IBaseDao<Student> {
    @Override
    public void add(Student student) {}

    @Override
    public void update(Student student) {}
}
```

## 四、泛型关键字与通配符

### 4.1 泛型字母命名约定

泛型字母（A-Z）无语法区别，仅为行业通用命名规范，提升代码可读性：

- **T (Type)**：通用具体Java类型
- **E (Element)**：集合元素类型（集合专用）
- **K (Key)、V (Value)**：键值对的键、值类型（Map专用）
- **N (Number)**：数值类型
- **?**：通配符，代表**不确定的任意类型**

### 4.2 核心限定关键字

#### 1. 无界通配符 ?

表示不确定的任意类型，可接收任意泛型类型的集合，提升方法通用性，且不允许修改集合元素，保证代码安全。

```java
// 可接收任意类型的List集合
public void add(List<?> list) {
    // 无法添加元素（类型不确定），仅可查询、遍历
}
```

#### 2. 上限限定 ? extends 父类

限定泛型类型：**只能是指定类及其子类**（上限）。

```java
/**
 * 仅接收Number及其子类（Integer、Double、Float等数值类型）
 * @param list 数值类型集合
 */
public void add(List<? extends Number> list) {
}

@Test
public void testGeneric23() throws Exception {
    List<Double> list1 = new ArrayList<Double>();
    List<Float> list2 = new ArrayList<Float>();
    List<Integer> list3 = new ArrayList<Integer>();
    List<String> list4 = new ArrayList<String>();

    add(list1); // 合法
    add(list2); // 合法
    add(list3); // 合法
    // add(list4); // 编译报错，String不是Number的子类
}
```

#### 3. 下限限定 ? super 子类

限定泛型类型：**只能是指定类及其父类**（下限）。

```java
/**
 * 仅接收String及其父类（String、Object）
 * @param list 字符串及父类集合
 */
public void add(List<? super String> list) {
}

@Test
public void testGeneric24() throws Exception {
    List<Object> list1 = new ArrayList<Object>();
    List<String> list2 = new ArrayList<String>();
    List<Integer> list3 = new ArrayList<Integer>();

    add(list1); // 合法，Object是String父类
    add(list2); // 合法，本身是String类型
    // add(list3); // 编译报错，Integer不是String父类
}
```

## 五、项目中泛型的实际应用

项目中泛型常用于**统一返回结果封装、分页数据封装**，实现通用响应体，适配所有业务接口。

### 5.1 通用接口返回结果类 Result\<T>

```java
// 全局统一接口返回结果，T为返回数据的泛型类型
public class Result<T> {
    // 状态码常量
    public static final int ERROR = 1;
    public static final int OK = 0;

    // 业务状态码：0成功、1失败
    private Integer code;
    // 前端展示提示信息
    private String msg;
    // 动态返回数据（不同接口返回不同数据类型，用泛型适配）
    private T data;

    // getter、setter、构造方法省略
}
```

### 5.2 通用分页封装类 PageInfo\<T>

```java
// 通用分页实体类，T为分页列表数据类型
public class PageInfo<T> {
    // 当前页码
    private Integer pageNo;
    // 每页条数
    private Integer pageSize;
    // 分页数据列表（适配任意实体类数据）
    private List<T> list;
    // 总页数
    private Integer totalPage;

    // getter、setter、构造方法省略
}
```
