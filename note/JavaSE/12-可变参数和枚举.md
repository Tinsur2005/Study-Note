# 可变参数和枚举

## 一、Java 可变参数

### 1.1 核心概念

Java 5 新增可变长参数机制，允许方法接收**不定长度的同类型参数**。方法声明中使用 `...` 标识可变参数，可变参数本质上是一个数组，方法内部可直接按照数组的方式操作。

可变参数支持传入 **0个或多个** 对应类型的参数。

### 1.2 语法规则

- **基础语法**：数据类型... 参数名
- **强制规则**：可变参数必须是方法的**最后一个参数**，前方可搭配普通参数
- **本质**：编译后可变参数会被转换为数组

#### 1. 无前置参数的可变参数

```java
// 可接收0个或多个String类型参数
public void method1(String... args) {
    // 内部可直接使用数组操作，如遍历、获取长度
}
```

#### 2. 带前置参数的可变参数

```java
// 普通参数在前，可变参数必须在最后
public void method2(String arg1, String... args) {

}
```

### 1.3 方法重载匹配规则

当固定参数方法和可变参数方法构成重载时，**优先匹配固定参数方法**，固定参数匹配精度更高，只有无对应固定参数方法时，才会匹配可变参数方法。

```java
public class VariableLengthArgument {
    // 可变参数方法
    public static void printVariable(String... args) {
        for (String arg : args) {
            System.out.println(arg);
        }
    }

    // 固定参数重载方法
    public static void printVariable(String arg1, String arg2) {
        System.out.println(arg1 + arg2);
    }

    public static void main(String[] args) {
        printVariable();                // 匹配可变参数：无参数
        printVariable("a");             // 匹配可变参数：单个参数
        printVariable("a", "b");        // 优先匹配固定参数方法
        printVariable("a", "b", "c");   // 匹配可变参数：三个参数
        printVariable("a", "b", "c", "d");// 匹配可变参数：四个参数
    }
}
```

> 1. 一个方法**只能有一个**可变参数
> 2. 可变参数必须位于参数列表末尾
> 3. 重载场景下，固定参数方法优先级高于可变参数方法
> 4. 可变参数底层是数组，支持数组所有操作
> 5. **平时不建议使用可变参数开发**

## 二、Java 枚举（enum）

### 2.1 核心概念

枚举是 Java 一种**特殊的自定义数据类型**，用于定义一组**固定、不可修改的常量**。

所有枚举项本质都是 **public static final** 的枚举类实例，全局唯一且不可修改。

### 2.2 基础枚举定义与使用

#### 1. 基础语法定义

使用 `enum` 关键字定义枚举，直接罗列常量项。

```java
// 定义颜色枚举，包含三个固定常量
public enum Color {
    // 本质：public static final Color RED = new Color();
    RED, GREEN, BLUE;
}
```

#### 2. 基础调用示例

```java
public class EnumDemo {
    public static void main(String[] args) {
        // 直接通过枚举类名调用常量
        Color color = Color.RED;
        // 直接打印枚举项，输出常量名
        System.out.println(color); // 输出：RED
    }
}
```

### 2.3 自定义字段与构造方法

基础枚举仅能存储常量名，实际开发中可给枚举添加**自定义属性、私有构造方法、getter方法**，实现常量绑定自定义数据。

> 枚举的构造方法必须是 `private`（默认私有，可省略修饰符）。

#### 1. 案例1：颜色绑定十六进制编码

```java
public enum Color {
    // 枚举项调用构造方法，传入对应参数
    RED("#FF0000"), 
    GREEN("#00FF00"), 
    BLUE("#0000FF");

    // 自定义属性：十六进制颜色码
    private final String hexCode; 

    // 私有构造方法
    private Color(String hexCode) {
        this.hexCode = hexCode;
    }

    // getter方法，获取属性值
    public String getHexCode() {
        return hexCode;
    }
}

// 测试使用
public class EnumDemo {
    public static void main(String[] args) {
        // 获取枚举绑定的自定义数据
        System.out.println(Color.RED.getHexCode()); // 输出：#FF0000
    }
}
```

#### 2. 案例2：季节多属性绑定（重写toString）

```java
public enum Season {
    // 传入多个参数，匹配构造方法
    SPRING("春天", "温暖"),
    SUMMER("夏天", "炎热"),
    AUTUMN("秋天", "凉爽"),
    WINTER("冬天", "寒冷");

    // 多个自定义属性
    private final String name;
    private final String description;

    // 多参私有构造方法
    private Season(String name, String description) {
        this.name = name;
        this.description = description;
    }

    // getter方法
    public String getName() {
        return name;
    }

    public String getDescription() {
        return description;
    }

    // 重写toString，自定义打印格式
    @Override
    public String toString() {
        return name + "（" + description + "）";
    }
}

// 测试遍历与使用枚举
public class EnumTest {
    public static void main(String[] args) {
        // values()：枚举自带方法，遍历所有枚举项
        for (Season season : Season.values()) {
            System.out.println(season + " 的特点是：" + season.getDescription());
        }

        // 单独使用枚举项
        Season currentSeason = Season.SUMMER;
        System.out.println("当前季节是：" + currentSeason.getName());
    }
}
```

**运行结果**：

```bash
春天（温暖） 的特点是：温暖
夏天（炎热） 的特点是：炎热
秋天（凉爽） 的特点是：凉爽
冬天（寒冷） 的特点是：寒冷
当前季节是：夏天
```

### 2.4 枚举与 Switch 语句结合

枚举搭配 switch 语句可简化分支判断，无需手动判断字符串/数值相等，代码简洁、安全性高，不会出现参数不匹配问题。

```java
public class EnumSwitchDemo {
    public static void main(String[] args) {
        Color color = Color.BLUE;

        // switch直接匹配枚举项
        switch (color) {
            case RED:
                System.out.println("这是红色");
                break;
            case GREEN:
                System.out.println("这是绿色");
                break;
            case BLUE:
                System.out.println("这是蓝色");
                break;
            default:
                System.out.println("未知颜色");
        }
    }
}
```

**运行结果**

```bash
这是蓝色
```

### 2.5 枚举的特性

- 枚举项默认是 `public static final`，不可被修改、不可被继承
- 构造方法强制私有，禁止外部创建枚举实例
- 自带 `values()` 方法，可快速遍历所有枚举常量
- 适配 switch 分支语句，简化多条件判断逻辑
- 可自定义属性、方法、重写父类方法，扩展性强
